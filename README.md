# ❤️ Heart Disease Power BI Dashboard

## 📌 Project Overview

This Power BI dashboard analyzes heart disease data and provides insights into patient demographics, cholesterol levels, blood pressure, chest pain types, and other important health indicators.

## 🎯 Objectives

* Analyze heart disease patient data
* Identify key health risk factors
* Visualize patient demographics
* Generate actionable insights through interactive dashboards

## 📊 Key KPIs

* Total Patients
* Average Age
* Average Cholesterol
* Average Blood Pressure

## 📈 Visualizations

* Gender Distribution
* Age Group Analysis
* Chest Pain Type Analysis
* Cholesterol Analysis
* Blood Pressure Analysis
* Heart Disease Risk Factors

## 🛠️ Tools & Technologies

* Power BI
* Excel
* DAX
* Data Visualization

Heart Disease Dataset
